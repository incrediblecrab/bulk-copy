# Change Log

All notable changes to the "Bulk Copy" extension will be documented in this file.

## [0.0.1] - Initial Release

### Added
- Copy folder structure with right-click context menu
- Configurable maximum depth (1-20 levels)
- Customizable indentation character and size
- Option to include/exclude root folder name
- Progress indicator for large folder structures
- Handles permission errors gracefully
- Protections against excessive memory usage
- Smart folder sorting (alphanumeric)
- Excludes hidden folders (starting with .)
- Limits folders per level to 1000 items
- Truncates structures over 10,000 folders
